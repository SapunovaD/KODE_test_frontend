# KODE_test_frontend

## Что это
Тестовое задание на стажировку KODE: список сотрудников компании с поиском, вкладками по департаментам, сортировкой и страницей деталей
Ссылка на задание: https://github.com/Hexlet/ru-test-assignments/blob/main/frontend/kode/trainee-test-frontend.md

## Что сделано
- Загрузка сотрудников с API
- Список с фото, ФИО, ником и департаментом
- Поиск по имени, фамилии и нику (без учёта регистра, с обрезкой пробелов)
- Вкладки департаментов
- Сортировка по алфавиту и по ближайшему ДР
- Экран загрузки, экран ошибки, экран "ничего не найдено"
- Страница деталей сотрудника: ДР, телефон с ссылкой, кнопка "Назад", При этом кнопка поиска исчезает
- После нажатия "Назад" сохраняются поиск и активная вкладка

## Что не сделано 
- Кэширование
- Тёмная тема, локализация, real-time отслеживание сети, GitHub Pages 
- React / Vite / Router / Axios - должно было использоваться, но нету

## Как запустить
1. Скачать репозиторий
2. Открыть папку с файлами
3. ПКМ открыть `index.html` с помощью "Live Server"

## Как проверяли
- Открывала список — грузится
- Вводила имя в поиск — список фильтруется
- Вводила не существующие данные — экран "Ничего не найдено"
- Нажимала на опр департамент — список фильтруется по департаменту
- Нажимала сортировку — переключается "А→Я" / "ДР"
- Нажимала на человека — открывается карточка с информацией
- Кнопка "Назад" — возвращает к списку, поиск и вкладка сохранены
- На странице деталей поиск скрыт
